## 1. Формули, розмірності та проміжні значення

Позначення розмірностей: $N = 105$ (об'єкти навчальної вибірки).

### Прямий прохід та розмірності
* **Вхідні дані:** $X$ — розмірність $(105, 4)$.
* **Шар 1 (Лінійний + ReLU):**
  * $W_1: (4, 8)$, $b_1: (8)$.
  * Передактивація: $Z^{(1)} = X W_1 + b_1$ — розмірність $(105, 8)$.
  * Активація: $A^{(1)} = \max(0, Z^{(1)})$ — розмірність $(105, 8)$.
* **Шар 2 (Лінійний, логіти):**
  * $W_2: (8, 3)$, $b_2: (3)$.
  * Передактивація (логіти): $Z^{(2)} = A^{(1)} W_2 + b_2$ — розмірність $(105, 3)$.
* **Стабільна функція втрат (крос-ентропія):**
  * Зсув на максимум: $m_i = \max_j Z^{(2)}_{ij}$.
  * Log-Sum-Exp: $LSE(Z^{(2)}_i) = m_i + \log \sum_j \exp(Z^{(2)}_{ij} - m_i)$.
  * Ймовірності: $P_{ij} = \exp(Z^{(2)}_{ij} - LSE(Z^{(2)}_i))$ — розмірність $(105, 3)$.
  * Втрата: $\mathcal{L} = \frac{1}{N} \sum_{i=1}^N (-Z^{(2)}_{iy_i} + LSE(Z^{(2)}_i))$.

### Проміжні значення для збереження
Для виконання зворотного проходу необхідно зберегти:
1. $X$ — для обчислення градієнта $\nabla_{W_1}$.
2. $Z^{(1)}$ — для обчислення маски похідної ReLU ($\mathbb{1}_{Z^{(1)}>0}$).
3. $A^{(1)}$ — для обчислення градієнта $\nabla_{W_2}$.
4. $P$ — для обчислення початкового сигналу похибки на виході $\Delta^{(2)}$.

### Зворотний прохід
* **Сигнал виходу:** $\Delta^{(2)} = \frac{1}{N} (P - Y)$ — розмірність $(105, 3)$.
* **Градієнти шару 2:** 
  * $\nabla_{W_2}\mathcal{L} = (A^{(1)})^T \Delta^{(2)}$ — розмірність $(8, 3)$.
  * $\nabla_{b_2}\mathcal{L} = \sum_{i=1}^N \Delta^{(2)}_i$ — розмірність $(3)$.
* **Перенесення сигналу:** $\Delta^{(1)} = (\Delta^{(2)} W_2^T) \odot \mathbb{1}_{Z^{(1)}>0}$ — розмірність $(105, 8)$.
* **Градієнти шару 1:** 
  * $\nabla_{W_1}\mathcal{L} = X^T \Delta^{(1)}$ — розмірність $(4, 8)$.
  * $\nabla_{b_1}\mathcal{L} = \sum_{i=1}^N \Delta^{(1)}_i$ — розмірність $(8)$.

## 4. Дослід із навмисною помилкою (прибрано ділення на $1/N$)

**Прогноз:**
* Функція втрат не зміниться, оскільки прямий прохід виконується коректно.
* Ненульові градієнти стануть рівно у $N=105$ разів більшими, оскільки відсутнє усереднення у початковому сигналі $\Delta^{(2)}$, яке лінійно переноситься на всі попередні шари.
* Звірка з PyTorch та чисельна перевірка виявлять помилку, оскільки `nn.functional.cross_entropy` у PyTorch усереднює значення автоматично, а чисельна похідна спирається на незмінену (усереднену) функцію втрат $\mathcal{L}$.

**Висновки:**
Дослід повністю підтвердив прогноз. Втрата залишилася ідентичною, проте всі градієнти NumPy 
збільшилися приблизно у 105 разів (наприклад, градієнт $W_2[0,0]$ зріс із $0.135$ до $14.199$). 
Це призвело до провалу обох перевірок, підкреслюючи критичну важливість правильного масштабування 
початкового сигналу $\Delta^{(2)}$ множником $1/N$ під час пакетного навчання.
